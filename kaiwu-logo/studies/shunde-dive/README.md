## 第二版：砖红经管楼、灰色空中连廊与树林硬地

第二版在第一版基础上做以下修订，前两版 MP4 均保留：

- **经管楼实图参照：**实际下载并查看[清华教育基金会新经管楼项目](https://www.tuef.tsinghua.edu.cn/info/1072/2664.htm)的[外观照片](https://www.tuef.tsinghua.edu.cn/__local/6/EF/BF/674CB4C9F380C0671EF1EAC94B1_1FF450B3_277C5D4.jpg)。可见砖红色／陶板色大板拼缝、高拱窗、深色细窗框、底部竖向红色翼片、上部玻璃体量和薄灰檐。模型用真实孔洞、玻璃、窗框、窗台、拼缝、屋面几何表达这些特征，未使用照片贴片。内部两段体量的分界及未见立面是构图下的近似，不是逐面测绘。
- **方位与身份：**清华[官方报道](https://www.tsinghua.edu.cn/info/1181/37409.htm)明确经管新楼位于舜德楼西侧，正对舜德北门时即画面右侧。替换该位置 OSM way 937482182 的普通灰楼，保留其平面轮廓，不重复叠楼；称“建华楼／李华楼组团”，不误标为伟伦楼。官方项目给出地上六层、总高30米；模型高区采用30米，红色低区分界是示意。
- **灰色连廊：**按用户最后更正，建在距地约**四层**的高度，不是五层。工作尺度取下缘13.2米（4×3.3），具有灰色顶／底板、窗带、金属框与端部接合；连接西侧经管组团和舜德西墙，下面保持真实悬空。端点受两栋源平面约束，位置、截面和内部接口为近似，不是工程结构模型。照片中能看到灰框高架连接，但没有确认其两端；不将官方“建华楼与李华楼之间的知识之桥”混称为这条舜德连接。
- **门前不再是空草坪：**原北侧近景草地区域上增加平整水泥硬地，细骨料纹理、实体伸缩缝与树池；增加14株分枝树、39,200片曲面实叶，保留楼前既有松树。用户已确认不抬高地形；树位和具体树种为示意。
- **靠近并留出右侧楼：**最终沿北向法线距离由57缩至43个模型米，向西平移18米让砖红楼和连廊进入画面；楼顶与上方徽章仍有留白。末段视角平滑放宽至63°，主楼东端允许少量出画，正门保留。四秒总长、开场、年份、徽章内部动作和配乐不变。

`src/sem-building.js`、`src/sky-corridor.js`、`src/forecourt.js` 均位于原 `projects/shunde` 工程，由此试验调用，原24秒查看器默认行为不变。GPU验收新增连廊三处首碰撞可见性、红楼画面右侧投影、无重复灰楼、最终前景硬地射线；相机还检查修订后的经管楼高度及新树冠净空。

第二版已导出至 `output\kaiwu-shunde-dive-2026-4s-v2-red-sem.mp4`：4.000秒、120帧、1920×1080、30fps、H.264／双声道AAC，18,026,153字节。已复制到 OneDrive 本地目录 `清华\开悟-2026-4秒徽章动画\清华MEM-开悟徽章-2026-4秒-舜德楼校园俯冲第二版-红楼连廊.mp4`，旁附新版来源说明；本地副本 SHA256 一致，未确认云端同步。实际编码帧为 `output\export-v2-contact.jpg`，音乐收尾报告为 `output\music-ending-proof-v2.json`。新版检查无运行时或布局错误；CLI保留0.8.58，新版安装缓存故障尚未解决。

## 第三版：正对正门、独立手绘背景与金属徽章

镜头最终回到舜德北入口的中轴线上，不再为展示右侧经管楼向西偏移18米；距离由43缩到40个模型米。两块入口牌匾的水平投影均为画面正中。右侧红楼与连廊保留在模型中，但镜头取舍以正门为先。最终徽章直径增大40%（比例0.30→0.42），中心降低约110像素（世界高度2.32→1.55）；允许徽章下缘与屋檐轻微重叠，正门与两块牌匾不被遮挡。

按用户指定采用真正分层、先背景后徽章的流程，不对已合成的视频整体套滤镜：

1. `passes/scene.html` 的 `renderPass=background` 单独记录天空、校园、树林和连廊，输出无徽章、无音轨的 `output\background-v3-clean.mp4`。
2. 对这段背景视频做独立油画／漫画手绘处理，输出 `output\background-v3-painted.mp4`。天空也随背景一起处理，色调比原模型偏暗。
3. `index.html` 播放已处理背景，顶层透明 WebGL canvas 只画原徽章。徽章的几何、2026镂空、粒子、书脊翻合、描边、金属材质、扫光与补光均复用原实现，未经过背景滤镜。独立 `renderPass=badge` 还可输出 `output\badge-v3-alpha.mov`（ProRes 4444，真实 alpha），供后续剪辑使用。
4. 原配乐仅在最终合成中加入，保持4秒总长、3.275秒收束、3.98秒静音。最终输出 `output\kaiwu-shunde-dive-2026-4s-v3-painted.mp4`，不覆盖旧版。

源场景GPU验收位于 `output\v3-source-proof`。分离前后11个时刻的徽章内部动作与灯光状态相同；最终80,215个不透明徽章像素与原合成渲染的RGB最大差异为0。`scripts\verify-layered.py` 检查各段120帧／4秒、真实alpha、背景单独变暗以及最终编码后的背景／徽章独立性，并生成最终成片联系表。

## 三种开源方案对比

第三版的 Kuwahara／排线方案未获用户接受，保留其研究输出，但不作为最终选择。用户要求另外制作三版全高清对照，允许马赛克风格，明确排除384×384小模型：

| 编号 | 背景处理 | 合成输出 |
|---|---|---|
| 01 | G'MIC `Paint With Brush` 方向性笔刷 | `output\comparison-v4\01-gmic-final.mp4` |
| 02 | PyTorch `fast-neural-style` 的 `rain_princess` 浓彩绘画 | `output\comparison-v4\02-pytorch-final.mp4` |
| 03 | ReCoNet `FRN mosaic` 浅色马赛克 | `output\comparison-v4\03-reconet-final.mp4` |
| 03B | 保留03碎瓷明暗纹理，恢复源场景颜色 | `output\comparison-v4\03b-reconet-color-final.mp4` |

三版共用 `background-v3-clean.mp4` 的全部120帧、同一中轴机位、同一放大下移的2026金属徽章、同一音乐和渐弱。算法仅处理独立背景，禁止把低分辨率推理放大后冒充原生1080p。它们是供用户比较的候选，不预先宣布哪一种胜出，也不把固定随机种子或时序训练等同于绝对无闪烁。

外部工具、隔离Python环境及模型缓存只放在忽略的 `output\comparison-v4` 下，不加入源代码或OneDrive交付。上游代码与权重的许可分别记录；预览不代表模型权重已获得单独再分发或商业使用许可。

三种初版和03B已复制到 OneDrive 本地目录 `清华\开悟-2026-4秒徽章动画\三种开源风格对比`，未确认云端同步。01保留用户先收到的浏览器合成预览；02、03及03B使用原生YUV合成，保留原徽章alpha通道素材和已接受的AAC音轨。旧浏览器合成保存在本地 `output\comparison-v4\browser-composites`，没有删除。

用户认为02过于浓烈，偏好03的纹理但要求能辨认蓝天。03B不是仅对灰白结果拉高饱和度，而是逐帧从相同机位的原背景恢复85%色度、保留85%的马赛克明度，色度倍率1.12；不处理徽章和音乐。运行 `python scripts\recolor-reconet.py` 可复现，三个参数分别为 `--source-color`、`--mosaic-lightness`、`--saturation`。文件名为 `03B-ReCoNet蓝天增彩-4秒.mp4`，浅色版仍保留。02采用固定风格权重；输出混合、饱和度和对比度可调，但换画风需要另一套权重。

背景处理完成后（合成脚本拒绝覆盖已有成片）：

```powershell
npm run check
npm run render:comparison
npm run verify:comparison
```

`scripts\comparison-variants.json` 定义三种背景。`render:comparison` 将处理背景与冻结的HyperFrames透明徽章素材直接在YUV域合成，避免再经浏览器RGB转换；音轨直接复制。`render:comparison:browser` 保留原HTML变量驱动的渲染途径，供Studio方案使用。`verify:comparison` 是严格的编码像素诊断：当前02在第40帧的背景RGB平均误差3.37，超过脚本3.0阈值，故三版统一数值验收尚未通过，也没有生成完整通过报告。没有为通过检查而放宽阈值；用户要求优先交付视觉比较，不继续阻塞在细微编码误差上。所有已交付视频均为4秒1080p；神经推理实测输入为 `[1,3,1080,1920]`，无缩小或切块。

## 画面编排

| 时间 | 画面 |
|---|---|
| 0–0.65 秒 | 原蓝天、薄云、粒子生成；没有建筑切入或替换背景照片 |
| 0.65–1.35 秒 | 同一透视相机快速下俯，楼与周边校园通过视锥自然进入画面 |
| 1.35–2.75 秒 | 高位俯视、加速下降；书页仍绕固定书脊翻合，1.85–2.75 秒徽章连续缩小上移 |
| 2.75–3.4 秒 | 镜头抬正，对准由实际北边界法线确定的入口正面 |
| 3.4–4 秒 | 正面停留；徽章保留四字描边、线性扫光、均衡补光和 2026 年份 |

直接复用 `sky-fusion/scripts/scene.js` 的徽章几何与全部内部动作；不是重做一枚相似的徽章。音乐仍是原本地合成完整乐句的 2 倍保音高播放，3.275 秒开始收束，3.98 秒渐弱至静音。

## 建筑优化与照片依据

已实际查看清华官方[舜德楼导览条目](https://vr.tsinghua.edu.cn/jsdl1/1133.jhtml)公开的[1920×1281 照片](https://vr.tsinghua.edu.cn/u/cms/www/202410/23095758a7g3.jpg)。条目发布于 2024-10-23，不据此宣称照片拍摄日期。可辨的识别点是小方砖墙面、灰粉色窗下板、窄屋顶窗带、窗框横梃与外开窗、双圆柱凹门廊、棕色杂纹石材、黑底金字竖匾、工业工程系白色横牌和宽台阶。

- 沿用原照片约束的楼体比例与现有方砖、石材 PBR，不把照片投影或贴成楼体。
- `createShundeModel(THREE, {refinedFront: true})` 开启真实后退的窗内空间、窗洞侧壁、凸窗台和较粗上横梃；补齐入口左侧窗网格的缺失墙带。
- 透明玻璃前后有几何层次；室内遮帘采用确定性不同开度。**逐窗遮帘开度属于示意，不是照片逐间复原，也未添加未经证实的办公室物品。**
- 天空、树木和周围楼体进入一次性本地立方体反射探针，玻璃不再仅依赖蓝色底色。场景使用日光、环境光、实体阴影；暂未做电影级路径追踪。
- 原模型 API 默认值、原 24 秒摄影路线和旧 Blender 快照保持不变。细化模块仍放在 `projects/shunde`，没有复制出另一套楼体。

## 周边环境：真实平面，示意立面

从 [OSM 官方 API](https://api.openstreetmap.org/api/0.6/map?bbox=116.3198,39.9947,116.3300,40.0023)冻结周边数据，使用与原楼体一致的 WGS84 ECEF→ENU 坐标。派生数据为 `projects/shunde/docs/campus-context.json`，保留源 ID、标签、原始响应 SHA-256、许可和高度依据。

近邻包含西侧建华楼／李华楼组团、北侧西配楼、南侧微电子所与公共管理学院、东侧建筑馆；另有更远的校园体量、道路及树木。不是把随机楼盒围成校园。主楼仍使用原 OSM way 84653293 的**伟伦楼＋舜德楼组合轮廓**，不把整个组团冒称为舜德楼单栋。

周边采用简化窗排和材料；有 OSM 楼层标签时按每层约 3.4 米估算，无可用高度时用明确标记的 15 米示意体量。**楼高、立面、屋面、路宽、补充行道树不是测绘复原。**道路中心线裁到 ±420 米；`area=yes` 步行广场按面处理；没有完整处理的多边形关系直接不纳入，不用实心体填掉其内院。门前近景仍保留原照片约束的示意台阶、铺地和松树，不将地图中心线当成精确台阶边界。

官方工业工程系[2026 宣传册](https://www.ie.tsinghua.edu.cn/qinghuadaxuegongyegongchengxixuanchuance2026.pdf)第 7 页可核实学院位于舜德楼、北邻主楼区及新清华学堂。它不提供测绘尺寸。当前是**参考重建预览，不是实景无人机航拍或实拍级数字孪生**。

## 本地运行

仓库已有依赖环境下，在本目录执行：

```powershell
npm run build
npm test
npm run proof
python scripts\contact-sheet.py
npm run render:background
npm run render:badge
```

先完成独立背景处理，再执行 `npm run check` 与所需合成命令。`npm run preview` 默认打开01背景的合成工程，并不表示用户已选定01；03B为离线源色恢复输出。`passes/scene.html` 是无处理的实时源场景，不应当成第三版成片。背景缺失会明确报错，不以原3D画面静默代替。各独立通道入口位于 `passes`，根目录只保留一个合成入口，避免被运行时误识别为多个主工程。

`CHROME_PATH` 可指定 Edge／Chrome。生成的 bundle、GSAP、字形和音乐全在本地；播放不请求外网。构建只复用本仓库素材，音乐缺失时调用原生成器。用户明确要求通过 OneDrive 视频查看；`npm run render` 使用CLI时间戳文件名，保留既有成片。

相机测试检查四秒终态、下俯超过 60°、无姿态跳变、不撞已导入的校园建筑；GPU 检查真正的入口居中、徽章放大下移、非顺序 seek 和完整时长。源场景联系表同时比较 0 与 0.6 秒和原版的实际像素；第三版成片背景有意风格化，不要求天空颜色与旧版相同。通用 HTML 检查不能判断 WebGL 内的建筑还原度，以实际帧图为准。

本机精确版本 `hyperframes@0.8.60` 启动遇到 npm `ECOMPROMISED / Lock compromised`，因此脚本保留可运行的 **0.8.58**。原建筑 `courtyard-details.test.js` 的源码字节哈希在 Windows CRLF 下有既存差异，LF 归一化后与原基线一致；未改写其摄影参数或放宽原断言。
