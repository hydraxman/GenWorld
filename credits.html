ABOUT THE EXPLORATIONS

空间开放，
来源清晰。

GenWorld 用交互式三维场景探索知识与建筑。本站仅发布精选场景与运行所需的许可素材，不发布参考照片、视频制作素材或本地研究文件。

代码与三维引擎

原创代码采用 MIT License；Three.js 使用 MIT License。校园几何计算使用 polygon-clipping、splaytree 与 robust-predicates，保留其 MIT / Unlicense 声明。完整源码与模型生成方式见 GitHub 仓库。

风向印刷所

生成海报使用 p5.js，独立加载未经修改的库文件，采用 LGPL 2.1 许可；对应的非压缩源码与运行库可独立获取和替换。文字、叶片及纸张由代码绘制，不复制示例图片。作品在本地生成与导出，不上传画布或个人数据。

知识学院与庭院素材

知识学院的人物与喷泉模型来自 Kenney，采用 CC0，详见模型来源。庭院枫叶贴图来自 Dorian Zgraggen / cgbookcase，采用 CC0，详见贴图来源。

校园地图与建筑

地图数据：© OpenStreetMap contributors / ODbL 1.0；地图服务与制图来源：OpenFreeMap / OpenMapTiles。处理后的地图数据库与相关定位输入按 ODbL 提供：校园数据库、数据来源、工字厅、二校门、老图书馆、舜德楼轮廓、周边轮廓。

二校门字形来自 LXGW WenKai，采用 SIL OFL 1.1，完整版权与许可声明随站点保留。字体、地图、模型与纹理不因仓库使用 MIT 而重新授权。

使用边界与个人数据

建筑为照片参照或地图约束的近似重建，隐藏立面、内部结构及部分尺寸含推定，不用于工程设计。知识学院测评仅作学习反馈，不代表能力认证；学习记录仅保存在当前浏览器，不上传。清除浏览器数据会删除记录，迁移前请在场景内导出。
