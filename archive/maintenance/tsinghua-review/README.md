# 历史诊断脚本

这两个小脚本曾用于清华导览项目的暂存区审计和地图瓦片加载诊断，作为历史源码留存，不是当前生产入口。

- `probe-frame33.cjs`：检查地图指定帧的瓦片状态、请求与截图。

保留原始字节，因此其中的旧机器路径已经失效。不要直接运行或据旧报告声称当前验证通过。当前可运行捕获、服务器和导出工具位于 `projects/tsinghua-tour/tools/`，生产回归测试位于其 `tests/`。旧诊断图、日志与补丁只保留在被 Git 忽略的 `local-assets/cleanup-evidence/`。
