# 庭院建筑 V3 · 光影、真实倒影与落地水池

## 本版修改

- **真实水面倒影**：三个水面各自使用镜像相机和平面反射纹理，每个镜头按相机位置重新渲染建筑和环境的倒影，不是预制照片或仅反射天空的环境贴图。首个正视镜头可以看到窗户与檐口的倒影。
- **水池支撑**：原来水池底板随阶梯抬高，而下面缺少实体支撑。本版增加连续石基及落地基础，池间过渡石台也补上支撑，消除悬空间隙。
- **光影**：重新平衡天空环境光、暖日光和补光；阴影贴图升级到 4096；增加 GTAO 接触遮蔽，强化墙根、窗框、檐口、柱脚和池基的空间层次。
- **质感**：砖红色不变，主楼砖纹升级为 1024 像素纹理并加强凹凸细节；保留石材、混凝土、金属和玻璃的材质区别。
- **植物**：增加原庭院树冠和藤叶密度，外围增加草丛与灌木密度，不改变主要镜头路径。

窗玻璃仍为统一灰蓝色，水面保留浅蓝绿色。V1/V2 均保留。

## 查看

`Courtyard3D-v3.glb` 是带材质的几何模型。**实时建筑倒影和接触遮蔽在本包的交互查看器与视频中实现**；标准 GLB 不封装实时反射相机/后处理，其他 3D 软件需要重新配置反射与灯光。

无需安装 npm 包即可打开交互查看器：

```bash
python3 -m http.server 8768 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8768/viewer.html`。左键旋转，滚轮缩放，右键平移；按钮切换五个视角。必须通过本地服务器访问。

## 源码与重建

- `src/model.js`：建筑、庭院、水池石基与原植物。
- `src/campus.js`：校园地形、步道及外围植物。
- `src/pools.js`：三个水池共用的尺寸、水位、基础参数。
- `src/water.js`：实时平面反射与可确定重播的轻微水波。
- `src/illumination.js`：环境遮蔽和色调映射。
- `src/main.js`：灯光、渲染、交互及模型导出。
- `src/camera.js`：与已认可版本完全相同的镜头源码。

Node.js 22+、FFmpeg 和 Chromium：

```bash
npm ci
npm test
npm run build
npm run check
npm run render
```

必要时用 `CHROME_PATH` 指定本机 Chromium。模型植物使用 `EXT_mesh_gpu_instancing`，需支持该扩展的查看器。Three.js 固定 0.181.2，HyperFrames 固定 0.8.24。

## 边界

36 秒、1080p、30 fps；镜头顺序、路径、看向点、缓动与 V1 一致。本版采用实时环境光照、阴影与 GTAO，不是离线路径追踪或完整光传输模拟。

模型来自两张照片的外观估算，背面及外围校园为合理补全；水景为用户指定的美术修改。池基与水位做了几何一致性检查，但不是结构计算、施工图或水力学仿真。
