# 庭院建筑三维模型与镜头展示

根据提供的两张照片完成的外观近似重建。**非测绘或施工模型**：尺度由照片估算，背面、不可见屋顶构造、门的位置及部分植被分布为合理补全。

## 文件

- `Courtyard3D.glb`：带纹理的三维场景，包含建筑、廊架、石池、铺地与植被。
- `viewer.html`：本地交互查看器，可旋转、缩放、切换五个视角。
- `index.html`：36 秒视频的 HyperFrames 合成入口。
- `src/model.js`：参数化模型源码。
- `src/camera.js`：五段镜头的坐标与时长。
- `src/main.js`：光照、阴影、材质环境与导出。
- `assets/scene.js`、`assets/gsap.min.js`：预编译本地脚本，不需要联网即可查看。
- `assets/reference-*.jpg`：原始参考照片，仅作为建模参考，不作为视频中的平面贴片。
- `MODEL_NOTES.md`：几何、材质、假设及构建细节。

## 查看模型（不需要安装 npm 包）

解压后在本目录运行：

```bash
python3 -m http.server 8768 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8768/viewer.html`。

左键拖动旋转，滚轮缩放，右键拖动平移；按钮切换正面、斜侧、廊下、立面和俯瞰。请用本地服务器，不要直接双击 HTML。

## 模型格式

GLB 包含 PBR 砖石、混凝土、屋面、铺地、树皮等纹理。绿植使用 `EXT_mesh_gpu_instancing` 扩展减小体积；推荐支持该扩展的 glTF 查看器。本交付已用 Three.js GLTFLoader 实际重新加载验证。

模型坐标单位按米估算，Y 向上，主立面朝 +Z。植被、建筑、栏杆等保留语义分组；同材质静态构件进行了批处理。需要改变具体构件尺寸时，修改参数化源码后重建比直接编辑合并网格更方便。

## 修改与重新渲染

Node.js 22+ 与 FFmpeg：

```bash
npm ci
npm test
npm run build
npm run check
npm run render
```

HyperFrames 固定为 0.8.24，Three.js 0.181.2。渲染可能需要配置 `CHROME_PATH` 指向本机 Chromium 可执行文件。`npm run build` 只编译模型脚本，不覆盖成片；新成片默认输出 `output/Courtyard3D.mp4`。

镜头：0–8s 正面推进；8–15s 斜侧环绕；15–22s 廊下步行；22–28s 立面横移；28–36s 庭院俯瞰。无背景音乐、口播和字幕。

## 还原边界

- 三段石池保持干池，没有添加喷水或虚构流水。
- 材质为本地程序化生成，不是现场采样的真实材质扫描。
- 窗玻璃用不透明反射材质表现，不包含室内空间建模。
- 两张照片未提供尺寸、完整四立面或背面，因此不能视为精确数字孪生。
