# 软件工程知识学院

可探索的三维知识大楼，包含学科展品、跨层导航、个人掌握度热力图与楼层试炼。楼层表示领域，不表示能力等级或强制学习顺序。[知识与空间规划](DESIGN.md)保留完整楼层结构。

## 运行

在仓库根目录安装依赖后执行：

```sh
npm run build:knowledge
npm run dev:knowledge
```

通过终端显示的 HTTP 地址打开。服务按需运行，不注册计划任务；退出后需重新启动。

## 使用与数据

- 支持整楼、展开和单层查看，以及搜索、先修跳转和推荐路线。
- 展厅独立记录自评与测评。未知不等于零分，浏览不自动增加掌握度，最近测评优先。
- 人物表示探索位置；示例访客与真实档案隔离。
- 试炼提供逐题反馈与徽章，不限制进入其他楼层，也不代表能力认证。
- 首屏可直接进入三个互动展台：3F 链表插入／删除／逐步反转、4F BFS 与 Dijkstra 最短路对照、15F 青蛙跳荷叶的马尔可夫链。也可选择对应展厅后再次点击三维展品，或点击“展开实验”；图解从桌面升起，收起后回到原展厅。
- 每个展台附三道有解释的小挑战。展台操作和答题暂不写入掌握度，关闭即重置；不把操作次数当作学习成果。马尔可夫实验使用固定种子、完整四状态转移矩阵和理论分布，单条轨迹的到达次数不等于第 n 步的概率。

三个实验的计算、三维展品与操作面板共用 `shared/knowledge-labs/`，同样放置在清华园舜德楼门厅内。继续使用已有 Three.js 渲染器；只播放有限的展开／跳跃动画，静止及隐藏页停止动画，收起释放临时展品。系统减少动态效果设置可跳过动画。

建筑的侧后围护、楼板和檐口共用层高基准，整楼状态接合，正面教学开口与主动分层展开保留。浏览器层复用 Courtyard PBR，木地板和石材使用六张共享颜色／法线／粗糙度图；按米制尺寸缓存 UV，不改 DOM-free 原模型的共享几何或学习状态材质身份。共享纹理由宿主释放，临时展台的 UV 几何单独释放。

界面保留知识、题目、结果与必要操作提示，删除免责声明、模型制作说明和重复口号。模型依据与资产许可留在源数据及维护文档，不反复占用场景、知识卡片和学习面板。[Long Wind 参考核验](../tsinghua-campus/docs/LONG-WIND-REUSE.md)记录本轮采用的思路及没有迁入的资源。

个人记录仅保存在当前浏览器与站点，可导出或确认清空。无账号、无上传、无跨设备同步；存储故障会明确提示，不静默覆盖旧记录。

## 验证与发布

```sh
npm run test:knowledge
npm run test:labs
npm --prefix projects/knowledge-tower run qa
npm run build:pages
npm run qa:labs
node projects/knowledge-tower/scripts/look-check.mjs
```

浏览器检查需要 Chrome 或 Edge，可通过 `CHROME_PATH` 指定。它使用临时服务与独立档案，不修改实际学习记录。Pages 将知识学院与其他精选场景整合到统一导航站点，仅打包各场景运行必需文件与许可说明，不包含测试、缓存或参考照片。
