# 软件工程知识学院

一个基于 GenWorld 现有 Three.js 技术栈的交互式知识学院：**16 层、64 个展厅、192 个代表性知识点**。建筑内部用对应学科的展品表达概念，并以独立的区域热力图、人物位置与楼层试炼记录成长。先阅读 [完整规划文本](DESIGN.md)，再进入三维场景。楼层高度不是水平或学习顺序。

## 启动

在仓库根目录执行；依赖统一使用根目录的锁文件：

```powershell
npm ci
npm run build:knowledge
npm run dev:knowledge
```

打开 **http://127.0.0.1:8785**，默认不使用已另有用途的 8784。若已有根目录 HTTP 服务，也可访问 `http://127.0.0.1:8773/projects/knowledge-tower/`。必须通过 HTTP 打开，不能直接双击 HTML。服务是普通 Node 进程，不注册计划任务或开机自启；退出或重启电脑后按需重新运行。

没有新增 npm 依赖或运行时 CDN。公共模型与贴图冻结在本地 `assets\models`，来源、提交与 CC0 许可见 [模型来源说明](assets/models/SOURCES.md)。生成的 `assets\scene.js` 与 source map 按仓库惯例不进入 Git。

## 使用

- **整楼 / 分层展开 / 单层查看**：查看整体结构、剖开内部或进入一层。拖动旋转，滚轮或双指缩放；重置视角恢复当前模式。
- **楼层与展厅**：点击左侧楼层、三维导视牌、展品或右侧展厅按钮，进入对应内容。非三维按钮覆盖所有知识，键盘也可操作。
- **概念与实践**：选择知识点查看短解释、动手任务和先修连接；先修按钮直达相关展厅。
- **检索**：搜索概念名、解释、展厅、楼层或英文主题。点击结果定位到对应展厅及知识点。
- **学习路线**：五条建议路线高亮所经楼层，可前后逐站浏览，也可随时跳到路线外。
- **规划文本**：页面右上角打开完整 Markdown，也可下载保存。
- **学科展品**：数组链表、Git 分支、动态规划、数据流、矩阵变换等各有对应几何表达；展厅面板解释展品表达的具体概念，而非只显示装饰图案。
- **我的档案 / 示例访客**：真实档案初始为空；示例是非线性掌握度和多名访客的演示，不是在线用户、不写入个人档案。人物代表当前探索位置，不代表已经掌握该层以下的知识。
- **掌握度热力图**：按 64 个区域独立着色，灰色为未评估，红色为薄弱（0–39），金色为巩固中（40–69），青绿为熟悉（70–84），蓝色为熟练（85–100）。浏览只记探索，不自动增加掌握度。
- **自评与试炼**：展厅可自评；每层设四道概念题，每个展厅一道，答对三道获得徽章。测评结果优先于自评，重做后可上升或下降；单题对错带来的 0/100 只是粗粒度线索，不是全面能力评价。
- **学习地图**：查看 16×4 区域热力图、最近探索和试炼记录，点击色块直接跳转；提供个人记录 JSON 导出和确认后清空。

## 个人数据与边界

个人记录保存在当前浏览器、当前站点的 `localStorage`（键 `knowledge-tower.learning.v1`），包含区域自评、最近试炼结果、最多 100 次试炼、探索时间与当前位置。不创建账号、不上传、不读取你在其他平台的学习历史；需要用自评或实际做题逐步建立档案。

更换浏览器、端口或设备不会自动同步。若存储被禁用、已满或内容损坏，页面明确提示临时记录，不静默覆盖旧数据；建议先导出，再排查或确认清空。清除浏览器站点数据也会删除档案。

每层试炼是可重复的形成性检查，不阻止自由进入任何楼层。徽章使用该层最新的保留测评结果，不因历史最高分掩盖当前薄弱项。它不是考试认证、完整题库或可靠的能力测量工具。

## 工程组织

`src\curriculum.js` 是知识数据来源；`navigation.js` 管理选择；`tower.js` 与 `exhibits.js` 创建建筑及学科展品；`learning.js` 和 `assessments.js` 管理档案与评分；`learning-ui.js` 连接个人界面；`public-assets.js` 加载冻结的 CC0 模型。几何、知识内容与学习记录分离。

沿用 Three.js 0.181.2、OrbitControls、esbuild 和 `shared\environment.js`。不改造或复制庭院、舜德楼与校园的现有实际建筑。

## 验证

```powershell
npm run test:knowledge
npm run build:knowledge
npm --prefix projects\knowledge-tower run qa
```

浏览器检查自动寻找 Windows Edge / Chrome；也可通过 `CHROME_PATH` 指定浏览器。检查使用临时端口和独立浏览器，不改写实际 8785 的个人档案；自动关闭自身服务和浏览器，在项目 `qa` 目录保存截图。覆盖全部展厅、三维交互、公共模型加载、非线性掌握度、刷新保存、示例隔离、试炼评分和徽章，以及手机布局。

这是带个人学习状态的空间原型，不是完整课程、第一人称游戏或逐概念算法动画。知识解释与先修关系是规划建议；后续可逐展厅补充教材引用、程序实验、更多题型与用户导入，而不必重建整楼。
