# 清华 MEM / 03、04

范围：仅本目录；原 awakening-wide 项目只读。真实源 SVG、semantic-geometry 和 SelectiveExtrudeGeometry 原样保留；原字孔不填，字形不重绘。沿用批准的 PerspectiveCamera / 紫色 PBR 金属 / 软箱反射。

交付每版 1920×1080 / 30fps / 5秒 / 150帧 / 无声 MP4 + 自包含 offline HTML。最后至少 0.7s 完整停徽，背景仍持续。

03「星尘凝徽」：碎星从画面宽翼高速涡旋收拢；同一噪声场控制实体阈值与薄发光边界，实体接管粒子，云星尘大幅平流。0–0.6s星云/星尘；0.6–2.8s凝聚生成真实实体；2.8–4.1s归正与金属反射；4.1–5s清楚停徽。

04「折光涟漪」：整幅连续液态虹彩表面，广域同心折射波环由中心推向边界；真实紫金属徽章经过径向折射显现并快速开书归正。0–0.5s液光压缩；0.5–2.4s径向显现/开书；2.4–4.1s折射消退/金属扫光；4.1–5s清楚停徽，水面持续流动。无星点，无云噪声，不复用03背景。

实现策略：自写绝对时间 GLSL；不用参考项目源码。采用原批准模型，不采用粒子替身完成画面。每版先3帧prototype；再 HF check、乱序seek、冻结输入、串行150帧PNG实际渲染、FFmpeg encode/full decode/ffprobe、离线HTML读回。
