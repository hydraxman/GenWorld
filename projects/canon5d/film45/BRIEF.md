# 45秒单反相机结构讲解

- Framework: existing Blender MCP project; native 3D animation, not an HTML re-creation.
- Source: ../canon5d-cutaway.blend, preserved unchanged.
- Master: 1280x720 native, 24fps, 1080 frames, 45 seconds (Eevee real-time rasterization, transparent teaching glass).
- Audio: Azure zh-CN-YunxiNeural, eleven measured scene clips.
- 0–8s: true 360-degree orbit, assembled body.
- 8–12s: exploded shell and component separation.
- 12–31s: viewing ray advances and pauses at lens group → aperture → mirror → focusing screen → pentaprism → eyepiece.
- 31–36s: mirror rises, shutter opens, exposure ray travels toward CMOS.
- 36–42s: image formation and photoelectric conversion at CMOS.
- 42–45s: image processor produces the photograph.
- Every taught component gets a tracked adjacent name tag, gold outline/highlight and a smoothly framed close-up. Subtitles follow the actual narration JSON.
- Lens train, prism geometry and internal arrangement are educational abstractions; always label this. Do not imply photons travel through the mirror during viewfinder operation or show an exposure path before opening the shutter.
- No music needed: prioritize clear explanatory speech.
