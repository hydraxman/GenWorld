# 45 秒相机讲解视频

## 成品

- `canon5d-45s-chat.mp4`：同分辨率聊天交付版，已单独验证时长、帧数、音频与最终抽帧。
- `canon5d-45s-azure-narrated.mp4`：较高码率母版，1280×720，24fps，45秒，H.264 + AAC。
- `canon5d-film45.blend`：保留全部三维部件、360°摄影机、拆解、光路、反光镜与快门动画。
- `audio/narration_45s_48k_pcm.wav`：Azure Speech 云希（zh-CN-YunxiNeural）旁白，原始48kHz PCM。
- `audio/narration_segments.json`：11个旁白片段、真实时长和保音调速度调整。
- `timeline.json`：逐帧名称标签与真实部件投影坐标。

## 内容顺序

| 时间 | 内容 |
|---|---|
| 0–8秒 | 完整机身360°环视 |
| 8–12秒 | 外壳及内部组件展开 |
| 12–16秒 | 镜片组：折射并汇聚光线 |
| 16–19秒 | 光圈：控制进光量 |
| 19–23秒 | 主反光镜：取景时向上反射 |
| 23–25.5秒 | 对焦屏：形成取景用像 |
| 25.5–28.5秒 | 五棱镜：改变光路和像的方向 |
| 28.5–31秒 | 目镜：画面进入眼睛 |
| 31–36秒 | 反光镜抬起，快门打开，曝光光路前进 |
| 36–42秒 | CMOS上的成像和光电转换 |
| 42–45秒 | 图像处理器处理电信号 |

蓝色表示取景光路，橙色表示曝光/成像光线，绿色表示电信号。每个部件有相应高亮、近景和跟随实际投影位置的中文标签。

## 说明和边界

- 基于本目录上一级已经制作的相机模型继续动画，没有下载或冒用 Sketchfab/BlenderKit 作者模型。
- 是原生 Blender 3D 渲染，不是静态图片缩放，也不是精密佳能CAD。外形和内构经过简化，照片来源见上一级README与references。
- 光线速度为教学放慢；棱镜折线和薄透镜示意不等于真实多片镜组光线追迹。玻璃采用实时渲染的透明混合近似，优先显示内部光路。
- 光线到达快门之前，快门已经打开；取景时没有让光直接穿过落下的主反光镜。
- `build_film.py` 是初始动画生成脚本；成品blend还包含预览后对玻璃通透性的修正与最终渲染设置。以成品blend为准。
- `compose.py` 消费实际逐帧PNG，并依据真实三维投影叠加标签和字幕；遇到尚未写完的PNG会等到IEND标记完整后再解码。

## 验收文件

- `verify_blend.py`：独立重开blend，核验360度环绕、展开位移、抬镜角度、全片没有光穿过关闭快门、无驱动器。
- `video-verification.json`：成品格式、时长、帧数、哈希与解码结果；视觉验收完成后更新。
- `audio/verification.json`：Azure旁白逐段时槽、无削波和解码验收。

上一级静态模型工程保留，不覆盖。
