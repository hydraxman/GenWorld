## 模型与坐标

- BlenderKit资产作者：sotilrac Asmat。原资产74个mesh、84,646多边形；拆分后V3命名前缀网格109个、134,565多边形（包含隐藏拆分组，不等于每帧可见面数）。
- 最终合装可见包围盒：最小 `[-3.990363, -5.098375, 0.494385]`，最大 `[2.798627, 1.897364, 6.070240]`，单位为场景坐标。
- 导入校准：机身源宽基准 `0.18585346639156342`；X轴旋转 `-0.033` 弧度；局部枢轴 `(0.0008,0.0483,0.0584)` 经相同旋转；整体放大36倍，镜头组Y方向再乘0.78；目标 `(0,-1.24,2.65)`。这些是艺术配准参数，不是实物测量值。
- 拆分分界：Z=4.28（顶盖）、Y=1.05（后壳）、X=-2（握柄）、X=-0.85（前/远侧）；镜头沿X=0划分。
- 展开组位移：rear `(0,6.4,0.1)`；top `(0,0.3,2.8)`；grip `(-2.7,0.1,0.05)`；front `(4.8,-0.3,0.7)`；far `(-0.25,0,0)`；lensnear `(4.9,-0.2,1.1)`；lensglass `(0,-0.6,0)`；lensfar不移。
- 第1–193帧外壳组零位移，第289帧完全展开；front/lensnear/lensglass在第289帧隐藏，避免遮挡内部。取景环绕第1–193帧累计360°。
- 材质修正由 `integrate_model.py` 与 `polish_materials.py` 负责：深色塑胶/皮纹，顶屏UV恢复并打包；镜片透明混合是教学近似，不是物理光学追迹。

## 时间轴

| 秒 | 内容 |
|---|---|
| 0–8 | 完整外观360°环视 |
| 8–12 | 展开外壳和内部组件 |
| 12–16 | 镜片组 |
| 16–19 | 光圈 |
| 19–23 | 主反光镜 |
| 23–25.5 | 对焦屏 |
| 25.5–28.5 | 五棱镜 |
| 28.5–31 | 目镜 |
| 31–36 | 抬镜、开快门、曝光 |
| 36–42 | CMOS成像和光电转换 |
| 42–45 | 图像处理器 |

蓝色=取景光路；橙色=曝光/成像光线；绿色=电信号。取景时反光镜向上反射；曝光光线经过快门之前，镜子和快门必须已避让。`verify_scene.py` 检查全1080帧，不仅抽查截图。

`timeline.json` 保存1080项原投影坐标；投影基准1920×1080，`compose.py`缩放到1280×720。标签24px、说明15px、字幕27px，标签框300×86px；字体为macOS STHeiti Medium。标签锚点来自真实动画物体，不是手工猜坐标。

## 旁白

- Azure Speech：`zh-CN-Xiaoxiao2:DragonHDFlashLatestNeural`；当时服务目录标记Female。此为请求来源证据，不代替人工听感判断。
- 11段，原文和时槽固定；原始/适配音频48kHz、16bit、mono PCM，母轨45秒。
- 最小SSML、服务默认语速；后处理FFmpeg `atempo` 保音调，上限1.45，实际最高约1.309028；没有删字或截断。
- 母轨增益约-1.232558dB；迁移核验的成片解码峰值约-2.061115dBFS。
- 所有文字、精确时槽和每段tempo见 `parameters.json`；完整来源、WAV哈希和测量见 `film45/replacement-v3/audio/narration_segments.json`。

## 准确性

精细外观采用实际下载的授权网格；内部镜片、棱镜光路、机械结构和拆分距离是教学示意，不能当作原厂CAD、精密尺寸、拆机顺序或维修依据。
