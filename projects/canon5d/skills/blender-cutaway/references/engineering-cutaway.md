# Engineering cutaway scenes

- Gather authoritative exterior photos, an official specification sheet and actual teardown photos before modeling a named product. Download and visually inspect reference contact sheets; distinguish directly observed layout from illustrative internals. Cite origins and do not call a simplified model a precise CAD reproduction.
- Use a new scene and a new project path. Keep outer shell, optics/mechanism, imaging/electronics and stage in separate collections; preserve the prior user project.
- Build assembled and exploded states with native position keys. Keyframe both `hide_render` and `hide_viewport` for removed shell halves; render-only hiding does not provide a usable interactive cutaway.
- Keep optical/mechanical work-cycle explanations distinct from explosion animation. For a DSLR, the viewing path reflects upward to focusing screen/prism/eyepiece; sensor exposure requires mirror-up and an open shutter. Generic lens groups and PCB layouts must be labeled schematic.
- Apply a Boolean aperture before the bevel, or explicitly move the Boolean to the top before applying. A warning about applying a non-first modifier requires inspecting the resulting opening.
- When a user asks for photographic fidelity or calls out crude back panels, research existing product models and real rear-view photos before adding more procedural noise. Missing controls, seams and screen surrounds are geometry problems; generic sofa leather is not a measured camera-grip material. Verify the asset-specific license and preview it, and distinguish downloadable listings from models actually downloaded/imported. A login gate requires user authentication, not extraction of protected viewer assets.
- Review low-sample previews for both states. Check missing shoulder/body covers, logos behind panels, near-side mirror walls hiding internals, rear shell in front of PCB, and exploded battery trapped in the grip. Fix the geometry and visibility instead of relying on captions.
- Render final PNGs with Cycles and inspect the final—not only preview—pixels. For accurate 2D labels, project real object bounding-box centers through `camera.calc_matrix_camera(...) @ camera.matrix_world.inverted()`; then place numbered leaders and a clearly separated legend with deterministic typography.
- Reopen the saved blend in an independent background Blender with automatic Python execution disabled. Assert both endpoint frames, visibility transitions, component motion, absence of unwanted drivers, no unpacked required images and disabled MCP autostart. Record hashes and visual acceptance separately.
- Preserve the final editable blend and a short viewing README. If a source script lacks post-preview fixes, identify it as an initial construction script rather than claiming it reproduces the final scene.
