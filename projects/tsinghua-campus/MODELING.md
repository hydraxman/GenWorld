# 建模依据与边界

维护当前约束，不重复记录版本历史、构件参数或测试总数。准确编号与相机配置以 `src/refinements.js`、`src/landmarks.js` 为准；几何参数及逐栋来源／未知项保留在模型 `userData` 中。

## 建模约束

- 源数据采用 WGS84；场景以 `data.metadata.center` 为投影原点，**X 东、Y 上、Z 南，单位米**。校园尺度近似不是测绘坐标系，无 DEM、地下结构或室内复原。
- 保留源轮廓、孔洞、可寻址根与局部原点。地图要素不一定对应独立楼号；批量矢量编号不能冒称 OSM way 编号，来源更新后必须重审分裂／合并及匹配。
- `renderHeight` 是顶部标高，`minHeight` 是底部标高；上游显示高度可能来自默认值或楼层推算，不是实测。照片推定高度与原基模高度分别记录。
- 建筑通过 `replaceBuilding(buildings, featureId, detailGroup)` 在原根内替换，细节使用该根局部坐标。重复应用不叠加模型，不新增重复身份；原轮廓证据保留。地标单独注册，搜索、拾取与导出共用同一对象。
- 从未挂接的新细节测量本地高度，避免隐藏基模或祖先世界变换污染结果。保持几何有限、资源可释放、程序纹理确定性，使用既有构建器合批，不为未提出的需求新增抽象。
- 照片只约束可辨认部分。朝向、背面、屋顶交接、构件数量及米制尺寸缺证时明确标为推定；不得用镜像窗列、拉伸或景观遮挡冒充完整测绘。
- `partial` 表示局部照片支持；`whole-footprint-estimate` 只表示全轮廓估算外壳。覆盖率不是还原度评分，收集照片不代表已接入模型。
- 先补充来源与限制，再注册模型并运行现有测试／构建；浏览器和导出验收不能由单元测试或历史截图替代。所有照片许可、地图署名和字形许可证继续保留。
- 未核实基模可显示可关闭的程序窗格，仅为体量阅读示意，不计入照片重建覆盖率；不据此声称真实窗位、楼层或材质。选中对象时保留原材质，不再以纯色覆盖窗户。
- 展示光照采用 Three.js 程序天空预滤波环境、方向光和 AgX 输出，不代表实地时刻。砖石颜色与法线分开处理；近景 GTAO 接触阴影可关闭，手机默认关闭，全校远景不计算。
- 外观验收同时查看校方照片和实际桌面／手机渲染，核对窗洞、框、遮挡和分段；自动检查真实帧中的窗墙明暗差，不能用“对象存在／导出成功”替代可见性或照片保真判断。
- 全650轮廓的结构覆盖与39轮廓的照片参照覆盖分别报告；611个程序外观为 `procedural-architecture-estimate`，不得算作新增照片重建或抹除核实待办。未命名、附属建筑和开敞构筑物同样保留独立身份与未知项。
- 程序模型的用途／社区楼层只读重叠验证的OSM建筑标签；缺失时保留原显示高度，不凭住宿／教学用途猜楼层。16个具名照片外观档案中，显式记录的立面比例可另外调整估高与窗列节奏，但不是实测或确认楼层数。裁切入口照不据此抬高整栋；无照片依据的屋面仍用中性估算盖顶，不凭风格补造红坡顶、标志、空调或室内。
- 16个照片配色轮廓单列为 `photo-guided-appearance-on-estimated-envelope`，仍包含在611个程序估算内，不增加39个照片模型或减少638个核实待办。墙面、框、玻璃、勒脚与屋顶配色同时进入近景、远景和完整GLB；窗型、遮阳、柱廊／拱廊等仅按可辨认部分加入，尺寸、朝向和未入镜面仍为估算。
- 近景真实开口合批，远景使用Three.js `BatchedMesh`，保留逐实例原编号拾取与筛选；显示批次不进入GLB，导出始终恢复完整结构。共享材质／程序纹理由校园批次持有，重建单栋只释放旧几何，整批释放时统一销毁共享资源。

## 逐处身份与朝向

下表概括可见依据，不替代完整来源记录；所有绝对尺寸和隐蔽部分仍受照片透视、遮挡及社区地图精度限制。

| 对象 | 身份、朝向与主要限制 |
|---|---|
| 舜德／伟伦组合院落 | 用冻结轮廓匹配既有模型，共用 ENU 定位转换，不凭目测缩放；不能误替换西侧新经管楼，隐藏立面与分界仍不完整。 |
| 经管建华／李华组团 | 与舜德共用原定位；通舜德连廊是示意推定，不冒称已核实的官方“知识之桥”，低区和隐藏构造仍待核实。 |
| 大礼堂 | 南侧凸出边与草坪关系支持南略偏东入口，是方向推定而非摄影机外参。浅金属穹顶、交叉坡顶、柱廊和入口山墙弧顶窗受照片约束；表面色差为程序示意，窗分格、背面、柱细部及高度为估算。 |
| 主楼组团 | 中央、东、西楼保留独立轮廓；[校方说明](https://www.tsinghua.edu.cn/info/2060/61191.htm)支持南向入口及组团身份。未逐一核实的过街楼不补造，侧后立面与阶梯标高为估算。 |
| 老清华学堂 | 不是新学堂；保留北向开放院落，东南斜切入口由照片和平面关系推定。北翼、院内和隐藏屋面简化补全；校名为原创几何示意，不是书法复制。 |
| 二校门 | 无冻结建筑轮廓，按独立 OSM 点位注册，不借邻楼身份。完整现代正面／斜视优先于历史或裁切照片，不恢复已拆短墙。尺度、厚度和北面为估算；WenKai 字形不是那桐手迹，未知小字省略。 |
| 西体育馆 | 正面按源南侧长边、运动场侧照片推定，不用全轮廓包围盒造假立面。三山墙和开放柱廊有照片支持，后部增建、年代分界与隐藏屋面未核实，属局部重建。 |
| 老图书馆入口 | 冻结根是未命名的现代／历史连通组团，不整体改称老馆。路线点在建筑外，不能靠最近楼匹配；标签解码和独立 OSM relation 重叠支持身份。仅东翼西向入口及邻翼细化，其余体量、庭院孔洞保留，属局部重建；现代庭院照片不是此入口。 |
| 工字厅／水木清华 | I 形主殿与南门房是两个原根；水木清华是主殿北后厦临池视角，不另造第三栋。门房显示名是照片／地图解释，不伪造 OSM 名称。南殿、侧院和遮挡面为推定，石狮、题字、精确彩绘省略。 |
| 科学馆 | 指中心草坪西侧的历史科学馆，不是生命科学馆或科学博物馆。东向长立面照片支持入口、组合窗与屋面；背面、端墙和被遮窗列为估算。全轮廓外壳不等于逐面照片验证。 |
| 同方部 | 两张照片均是西侧匾额门，不是朝南主门廊。[校档案](https://dag.tsinghua.edu.cn/info/1062/2581.htm)支持西部单层、东部两层及南入口关系；分界、南廊形式、东屋顶与隐蔽面仍为推定，属局部重建。 |
| 老化学馆 | 不是新化学馆或何添楼；历史／合影与近年入口照片互证身份，拍摄点支持南向入口。仅中央入口有细节依据，两翼、背面及女儿墙后屋顶未知；中性封盖不证明平屋顶，属局部重建。竣工时间不等于照片拍摄时间。 |
| 艺术博物馆 | 原东侧凹口与独立根不变；校方高机位和斜视支持开放柱廊、分带石材、上层筛墙及屋顶采光阵列。柱数、采光器数量和尺度估算，背面未逐面核实；不复刻雕塑与题字。 |
| 综合体育馆 | 不是西体育馆或游泳馆；矩形原轮廓作平台，椭圆馆体、分层窗带、穹顶与白色拱架比例受官方正面照片约束。像素标记未做相机标定，背面、结构剖面、投影及标高仍为估算，不是施工模型。 |
| 蒙民伟音乐厅 | 不是蒙民伟人文楼或学生活动中心；保留西侧附属体，南立面的宽高、倒三角窗和门组位置受官方外景近似像素比例约束，避免过高墙体与放大窗洞。未做相机标定，背面与后屋面仍为估算，属局部重建。 |
| 紫荆公寓1–23 | 已建本轮有官方编号依据的1–23号楼，保留20个地图根：14–17原本合并为W形轮廓，按独立具名OSM way的共同边界在根内分为四楼，不借“14公寓”等旧宿舍身份。1–13坡顶、14–17 W高层及18–23条形高层分型；真实窗洞、退入玻璃、窗框、分带和开敞栏杆为合批几何。校方照片支持的是组团类型，不是每栋逐面照片验证；楼层依据、窗列、红灰屋顶分配、入口、遮挡面及高度仍有估算。14–17是博士楼，19–23为国际公寓，18不强归入后者；不证明不存在更新楼号。 |
| 紫荆园／桃李园餐厅 | 原轮廓不变；饮食服务中心的识别卡外景分别支持横向弧形分带与顶部构架／大圆窗构图。官方总层数含地下一层，模型只建紫荆园地上四层、桃李园地上三层，不把地下层加到地上。小图不能约束背面、完整弧线与入口朝向，属局部参照重建；无室内与地下模型。 |

## 可追溯证据

- [reference-catalog.json](reference-catalog.json) 保留工作台照片发布页、原图 URL、哈希、尺寸、署名、许可、可见内容及未知项；实际接入与阶段由注册表和运行生成的覆盖报告决定。
- [data/provenance.json](data/provenance.json)、冻结边界、TileJSON、名称提取和 `source-cache.json` 保留地图来源与离线重放依据；哈希输入不是可随意清理的缓存。
- [data/old-library-match.json](data/old-library-match.json) 保存原轮廓、独立 relation、路线点、标签与重叠证据；[data/gongzi-source.json](data/gongzi-source.json) 保存主殿／门房身份、方向解释和来源核验限制。工字厅的 [OSM XML](data/gongzi-entrance-osm.xml) 是默认测试必需的 ODbL 输入，不是可选照片。
- [科学馆](data/science-hall-references.json)、[同方部](data/tongfang-references.json)、[老化学馆](data/chemistry-hall-references.json) 的独立记录有额外身份、字节数、版权及审阅证据。名称关联置信度不等于独立计算的 IoU；来源核验限制不能因文档精简而抹去。
- [现代建筑身份](data/modern-building-sources.json) 固定艺术博物馆、综合体育馆和音乐厅的原轮廓、名称关联与朝向解释；与照片索引共同约束模型替换，不包含照片像素。
- [紫荆证据](data/zijing-evidence.json) 区分历史住宿分配、当前官方住宿说明、具名W楼外景与楼层估算；`src/zijing-sources.js` 固定20个轮廓签名和23个逻辑楼号。覆盖报告单列组团类型推定，分楼导航、拾取及GLB导出仍保留原地图根身份。
- [全轮廓建筑类型证据](data/architecture-evidence.json) 保存冻结输入SHA-256、逐轮廓漂移签名、单一OSM way交并比及建筑标签白名单；来源是历史本地OSM提取，不是实地勘察。不能把社区类型标签、展示层高或程序窗格解释为照片已核实。默认模型只增加可读建筑结构，不承诺未知真实屋顶、精确窗位与材质。
- [对应照片外观档案](data/appearance-profiles.json) 增加15处官方来源的18张照片和16个具名轮廓映射，原照片只在忽略的本地目录审阅。所有名称、来源、角色和几何签名在建模前核验；默认测试从冻结具名OSM多边形重放对应关系。六教A来源way位于合并根内，不表示整根均为A；法律馆为廖凯原楼、人文馆为凯风楼，不能将后者室内金色书架当成外墙颜色。`src/reference-catalog.js` 合并为33处／50张的元数据索引，不改变照片许可。
- 化学馆原 JPEG 的编码尺寸与 EXIF 转正显示尺寸不同；审阅图有自己的哈希与派生说明，不重复计为原发布照片。Commons 作者 **葉又嘉**、**HoweyYuan** 的图像适用 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)；同方部原图保留摄影 **李派** 等署名，章节作者不能代作未明摄影者。
- 字形来源和近似边界见 [src/second-gate-wenkai.json](src/second-gate-wenkai.json)，完整上游版权与 SIL OFL 1.1 见 [src/second-gate-font-OFL.txt](src/second-gate-font-OFL.txt)。不需分发完整字体。

来源可公开查阅不等于取得照片再发布许可。参考照片只作合法本地研究，不作为模型纹理、不去水印；自有源码 MIT 与第三方数据／字形／照片许可分别处理，见 [README](README.md#许可)。
