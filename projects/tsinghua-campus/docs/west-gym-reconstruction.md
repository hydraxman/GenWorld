## 正面方向：来自源边，照片只作语境验证

使用源外环 **第 3→4 边（从 0 计数）**：

```text
[116.314664483, 40.003522513] → [116.315297484, 40.003559496]
```

该边投影长约 **54.135 m**，东西切向 `[0.997104066, -0.076049208]`。
正面向外法向：

```text
X/Y/Z = [0.076049208, 0, 0.997104066]
```

即**朝南、略偏东约 4.36°**，不是未经几何核对的纯南向。该边南侧冻结绿地
`landcover:11785304122` 的中心相对正面中点具有正的法向投影；
与照片前景的跑道/运动场语境一致。这支持将此长边当作历史正面，但绿地
自身没有“运动场”语义属性，不能把它当成独立测绘方位证据。

该边中点在根局部坐标约 `[-5.946812, 0, 23.786304]`。
所有照片立面坐标先以此中点为原点，再按源边旋转，根建筑位置与 UUID 不变。
整个南端包围盒最南边属于东侧突出体量，不应据此拉出一条 84 m 假正面。

## 轮廓、屋顶与不可见增建

基座按原多边形挤出；所有屋面先与原多边形求交再三角化。
三面正墙不是整块填充的房盒，低翼坡屋面分成真实独立平面，
中馆有前后两坡及连续天窗。柱廊只在柱位置有石材，下层前面没有整墙。
栏杆也是细杆与柱间开放空间，不是透明矩形代替。

历史正面和它后方的估计馆体分区，不自动等同于历史建设年代边界。
西侧条带、北侧折入/突出体量、东侧向南及向北突出体量都保留冻结
轮廓；它们与不可见后翼统一置于 `inferred-additions` 组，标记
`inferred-not-visible-in-front-photo`。这些通常应与后来增建区别展示，
但本轮没有核实竣工档案，因此不杜撰年代、精确高度或完整后立面。
这些组采用安静的简化墙体和逐多边形屋面，没有套用正面的三拱窗。
凹入空地、南西侧退台、北侧缺口没有跨空地的矩形屋顶或大底板。

## 接口与性能

```js
export const WEST_GYM_ID;
createWestGymDetail(feature, center, localOrigin); // 未挂接的 Group
refineWestGym(campus, data);                      // 返回原有建筑根
```

冻结源环、OSM 名称身份、投影中心、局部原点以及根变换改变都明确抛错；
不吞异常，不静默退回通用盒子。只原有地址根携带 `featureId`。
`replaceBuilding` 隐藏旧 base，并移除上次 detail；重复调用不增加双份模型，
本模块随后释放被替换的自有几何/材质。

在挂接前测量**独立可见 detail** 的 Box3 并更新根 `renderHeight`；
不测根 Box3，因为 Three.js 会把隐藏的旧 base 也计入。
保留 `baseRenderHeight=5` 供说明。引用、估高依据、朝向、尺寸、
像素比例及未知项均进入新组 `userData`。

使用现有 `createBuilder` 按组/材质合并，窗格、柱和栏杆没有产生数千独立对象。
砖/瓦纹理是小型确定性的程序 DataTexture，不加载图片纹理。

## 首次截图后的限定屋面表面修正

已查看主任务提供的 `output/west-gym-reconstruction.png`，并与上述官方原图对照。
截图中的大面积点状/条状瓦纹明显比原照片的暖色规则瓦面突兀。
针对实际生成模型增加三项窄回归：纹理缩小过滤、每个裁切坡面三角形的
连续 X/Z 仿射 UV，以及屋面/砌体顶盖近共面面积重叠。

未修正模型的过滤测试为红：`minFilter = NearestFilter`（1003，而非
`LinearMipmapLinearFilter` 1008）；`DataTexture` 默认还关闭自动 mipmap，
各向异性为 1。原瓦图有高反差的单像素深缝和逐像素噪声，
近景瓦纹缩小到约像素尺度时容易出现点状跳采样与条带。
这确认了过滤缺陷；UV 连续性与共面重叠检查则通过，未发现需要删改的
重复坡面或跨大面积的屋顶/墙盖深度冲突。该模型层诊断不等于重新运行浏览器
复现同一帧的完整像素输出。

修正仅限自有生成纹理：瓦面改为低反差、暖棕色、规则瓦垄与横向搭接，
去掉逐像素瓦噪声和深色细棋盘缝；显式启用 trilinear minification、
自动 mipmap 与 8× 屋面各向异性（由 Three.js 按硬件上限裁切）。
共享纹理函数的砖纹也显式设置 mipmap/线性过滤和 4× 各向异性，
砖纹颜色与几何不改。没有使用 emissive、polygon offset 或删屋面来掩盖问题。

源轮廓、分区、立面/屋顶标高、屋脊、0.65 m 世界 UV 周期、根身份/位置、
16 个合批 mesh 以及所有不可见增建推定说明保持不变。材质表面规则并不新增
实测瓦尺寸的主张。最终浏览器截图对照仍由主任务验收；本轮不执行浏览器
或修改父任务 QA/相机。
