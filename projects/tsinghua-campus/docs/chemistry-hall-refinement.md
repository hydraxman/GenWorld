## 交付接口

```js
import {
  CHEMISTRY_HALL_ID,
  refineChemistryHall,
} from './src/chemistry-hall-refinement.js';

// 使用由 createCampusModel(data) 建立的模型和未修改的冻结校园数据：
const root = refineChemistryHall(campus, data);
// CHEMISTRY_HALL_ID === 'building:geometry:ad7b725c774db745829afef8'
// root === campus.buildings.get(CHEMISTRY_HALL_ID)
```

仅导出上述常量和函数。调用 `replaceBuilding` 隐藏原 `base`、替换详细子组，**不是移除或另造地址根节点**。原 root、定位、`campus.objects` 和建筑 Map 引用不变，`featureId` 只由 root 拥有。重应用替换旧细节并释放旧细节的独占 geometry/material/texture；不释放原 base 或邻楼材料。

`root.userData` 提供独立的 `referenceSite='chemistry-hall'`、`referencePages`、`refinementSummary`、`heightSource`、`unknowns`、`dimensions`、`reconstructionExtent='partial'` 和 `focusBoundsLocal`。`baseRenderHeight=5` 保留原显示高度，`renderHeight≈19.32` 是估计几何自身的 Box3 最大 Y，不是照片实测高。冻结 Feature 中 `renderHeight=5` 不变。

推荐将来接入时的 registry 信息（**这里只提供建议，没有修改 registry**）：

```js
{
  featureId: CHEMISTRY_HALL_ID,
  referenceSite: 'chemistry-hall',
  label: '化学馆（老馆）',
  reconstructionExtent: 'partial',
  viewDirection: [0.06316347282630623, 0.28, 0.9980031942336258],
  apply: refineChemistryHall,
}
```

`viewDirection` 是从焦点指向相机的方向，南侧略偏东、略抬高；不是朝向建筑的视线向量。南立面水平法线 `[0.06316347, 0, 0.99800319]` 来自实际长南边。局部坐标 X 东、Y 上、Z 南，以冻结 bbox 中心为 root 原点。入口几何自身另用旋转到长边的 u/v 框架，生成后转回 root 局部米制空间。

## 1. 身份核验：三座建筑不能混用

| 冻结 ID | 原数据名字 | 名称关联 |
|---|---|---|
| `building:geometry:ad7b725c774db745829afef8` | **化学馆：本模块唯一目标** | `osm:way:83801034`，重叠置信度 **0.934** |
| `building:geometry:fac61644977c4c3514669704` | 新化学馆：不修改 | `osm:way:1337324769` |
| `building:geometry:15ccb810d680210fe04fa0bf` | 化学馆新馆（何添楼）：不修改 | `osm:way:85480383` |

关联来自 `data/campus.json` 的冻结属性和 `data/osm-names.json`，是社区地图重叠匹配，不是大学测绘授权。源码锁定目标 ID、名字、OSM 关联、置信度、十个轮廓点和投影中心；漂移时抛错而不套用照片。

**历史身份的第一方证据：**

1. 清华化学系百年系庆《1932年》页面明确标注“1932年12月，化学馆建成”，配长馆体、重复竖向立面和水面倒影的历史照片。网页发布时间是 2025-04-24；**不得把竣工年月直接当作相片拍摄年月**。[官方页面](https://100.chem.tsinghua.edu.cn/info/1017/1030.htm)
2. 清华化工高分子所《十年之忆 | 元旦晚会与化学馆》正文有“老化学馆的故事”专节，描述红色砖墙、爬山虎以及三楼活动；图注为“2008年分4班毕业合影于化学馆”。门额、砖墩、深色双门和石阶与后述近年图片一致。文字证明至少有三楼，**不独立证明总楼层数**。[官方文章](https://polymers.chemeng.tsinghua.edu.cn/info/1504/2656.htm)
3. 清华大学《罕见规划图带你见证清华校园百年变化（一）》说明沈理源参与建设及仿康乃尔化学馆设计。其“小河北岸”叙述是规划背景，文章也说明部分规划没有建成；**不将规划图直接充作入口朝向或实测平面**。[官方建筑历史](https://www.tsinghua.edu.cn/info/1661/55995.htm)
4. 清华教育基金会《基建项目 | 新化学馆》明确列出新馆 2018 年 10 月奠基、2023 年 11 月移交验收、地上四层地下三层。该页效果图和外观图**不用于1932年老馆**。[排除来源](https://www.tuef.tsinghua.edu.cn/info/1073/2680.htm)

初次检得的两张官方照片只有 305×235 / 369×281，单靠它们不足以重建现貌细节。因此继续取得摄影者本人发布的 2019 / 2024 年较高分辨率原图，并逐图目视核对，而不是凭新馆图或搜索工具的建筑概述生成。搜索概述中“四层平顶”等未核实结论**没有作为建模事实采用**。

## 3. 模型中支持的特征与推定边界

### 真实建出的南中央特征

- 约12.8米宽的局部砖立面；长向竖砖肋柱，**不是白色古典圆柱**。
- 阶梯式顶部：局部外围17.2米、肩部18.15米、中部19.2米，中央小帽19.32米。不是坡屋顶山花。
- 中央上两层各三扇窄矩形格窗，玻璃位于墙后，外框、上亮及小格为几何；砖墙开口真实挖孔，层间保持砖填充板，不作六条贯通玻璃带。
- 邻近两侧各三处可见窗口片段简化，**没有**向整个两翼/背部复制规则窗网。
- 上部浅石长壁板、圆顶扇形贝壳浮雕和两旁嵌板。浮雕轮廓简化，不仿精确雕刻。
- 矩形浅石门额与高石基脚、砖门墩，深色双扇分板门、简化门旁灯及无文字牌面。
- 约17级宽石阶、上收下放的宽度和低砖侧墙。门额题字留白，不用照片贴图或近似字库冒充原书法。

### 参数是估计，而不是立面测量

3.32米门高、2.18米门宽用于常规构件尺度锚定。照片中窗口高宽约2:1、三联窗间的窄砖肋、两层间砖板、较高顶部壁板/女儿墙和阶梯的比例被保留；照片透视、仰角、不同深度没有摄影测量校正。下表**绝对数值均为建模估计**：

| 构件 | 模型参数 |
|---|---:|
| 主体安静体量顶/屋面下表面 | 16.2 m |
| 中央女儿墙/帽最高点 | 19.32 m |
| 东连廊墙高 | 5 m，沿用原显示值，未核实 |
| 入口平台 | 2.92 m |
| 三联单窗宽×高 | 1.18×2.48 m |
| 上两层窗下沿 | 8.1 / 12.1 m |
| 阶梯级数/单级高 | 17 / 0.16 m |
| 阶梯进深 | 5.44 m |
| 阶梯底宽/顶宽 | 10 / 6 m |

级数是2024正面目视近似，扶墙造型、精确收坡、平台、窗框格数和 relief 的凹凸都只作结构层级估计。无档案图，不据不清晰历史图恢复全馆逐窗或断言总楼层为某个确定数字。

### 明确没有还原的部分

- 女儿墙后的真实屋顶拓扑、坡向、材质、设备均未知。中性、低对比程序材质的平盖只是关闭估计体量，**不是确认老馆为平屋顶**；不添加未经证实的瓦脊、坡顶或天窗。
- 当前两翼被树藤遮挡，侧后立面、地下窗未知；安静红砖主体保持地图形状，没有镜像南门到北墙，也没有给它们虚造窗排。
- 东连廊保留完整精确平面和折角，高度/表皮/年代未确认，低细节估计。未编辑东侧何添楼或北侧新化学馆。
- 不建照片中的人物、临时通知、空调机组、爬藤或树丛来掩盖立面缺失；没有照片纹理。

## 4. 局部焦点与性能

`focusBoundsLocal` 在**原 building root 的局部坐标**，含中央南立面、装饰、窗、门和外部阶梯，不含未知完整两翼/后墙。它由尚未附着的详细子组的真实顶点 Box3（`precise=true`）联合计算，已包含子组相对于 bbox 原点的平移和转角：

```json
{
  "min": [-13.96157392757327, 0.19999995827674866, 9.436870895095495],
  "max": [-1.160604194098334, 19.31999969482422, 16.390285764156538]
}
```

焦点中心约 `[-7.5611,9.76,12.9136]`；不是完整 bbox 中心。石阶向冻结长边以南外伸约5.76米，是门前附属构件，不改变建筑源 polygon。完整 detail bounds 为 X约±45.0582、Y 0.08—19.32、Z -12.5792—16.3903米。

当前详细模型：**20个材质/语义组批次、8708顶点、4096三角形**（不含隐藏原 base 或邻楼）；**2张64×64程序 DataTexture**。复用既有 `createBuilder` 对同组同材质几何合批，不为每扇窗/每一级阶梯建立渲染 Mesh。

纹理只生成砖砌和安静屋面低频纹理，显式：

- `generateMipmaps=true`
- `LinearMipmapLinearFilter`
- `LinearFilter`
- `anisotropy=8`（渲染器可按设备能力夹取）
- SRGB、RepeatWrapping、世界米制 UV

不会调用图片加载器，不使用任何参考照片作为材质。

## 6. 测试与交付边界

只运行：

```powershell
node --test projects/tsinghua-campus/tests/chemistry-hall-refinement.test.mjs
```

**9项通过**，全部通过公开 `refineChemistryHall(campus,data)` 调用，不导出内部工厂绕过集成行为。检查：

1. 冻结ID、OSM/名字关联、原root/base和源 JSON 完整保留，两个指定邻楼根/几何/元数据不变。
2. 精确多边形、凹角、面积、跨度，以及主体/细连廊分区，实际 foundation 顶盖三角形面积而非只信 metadata。
3. 南向边框架及2019/2024相机点所处半平面。
4. 六个中央上窗是真墙孔和后退玻璃，砖填板保留，背面没有复制入口。
5. 阶梯式女儿墙、真实贝壳简化几何、矩形门口、17级台阶的实际几何。
6. 全部几何属性有限、合批数量、程序纹理过滤；人为将隐藏 base 拉高到500米，再应用仍由 detail-only Box3 得到19.32米。
7. 重应用不重复、材质/纹理/几何释放一次、几何确定性。
8. 错名字、何添楼OSM关联、置信度、源轮廓、投影、root定位等漂移立即阻止细化。
9. SITE结构、6张本地图像hash、JPEG编码尺寸、页面和本地用途许可一致。

尚未做浏览器渲染、全馆 QA、服务器或 UI验收；这是用户指定的交付停止边界。模型的强证据区域只在**南入口中央**，完整地图占地不等于完整照片还原。要升级为 `whole-footprint-estimate` 或更精确的全馆重建，需要去除树藤遮挡的南两翼、北背面、侧面和屋顶照片/测绘平立剖图，并重新核实连接体。
