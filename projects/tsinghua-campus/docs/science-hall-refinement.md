# 科学馆（1919）照片参考重建

验证方式更新：默认测试保留冻结身份、IoU、几何和独立SITE的来源/尺寸/哈希元数据断言，照片字节检查明确显示跳过。原始PNG字节数、SHA256、签名与编码尺寸断言由 `npm run test:references` 严格执行，缺图即失败；默认构建仅生成不带图片的来源页，不分发照片。

## 导出与待集成接口

文件：`src/science-hall-refinement.js`。**恰好两个导出**：

```js
export const SCIENCE_HALL_ID = 'building:geometry:91ba4cc6c7a0d501736a0fec';
export function refineScienceHall(campus, data);
```

调用后返回原来的 `campus.buildings.get(SCIENCE_HALL_ID)` 根对象，不创建第二个建筑根、不新增地图ID。通过 `replaceBuilding` 一次附加 detail 并隐藏 `base`；重调用只替换旧 detail，释放其几何、材质、生成纹理。源数据及其他建筑不变。

待集成建议（本次**未修改**注册表、主程序、UI、全局图库或覆盖率）：

- `referenceSite: 'science-hall'`
- `viewDirection: [0.9977520746672028, 0, -0.06701341281633451]`
- 此向量是**目标朝前侧相机的偏移方向**，即从东偏北约3.84°看正门；不是相机向目标的视线方向（后者取负）。
- `reconstructionExtent: 'whole-footprint-estimate'`：整个冻结四边形有外壳，**不是**完整精确立面复原；西侧和端部缺少照片。
- 坐标：米，X东、Y上、Z南；原根位于 `[-195.7960123018143, 0, 8.871551159235187]`。detail 单独应用源边导出的平移及yaw；不旋转/移动根。

## 身份核验：不是生命科学馆

冻结 `data/campus.json` 中目标名为“科学馆”，名称来源为建筑**多边形重叠**：

| 项目 | 结果 |
|---|---|
| 建筑ID | `building:geometry:91ba4cc6c7a0d501736a0fec` |
| 名称来源 | `osm:way:79701310` |
| 冻结名称关联置信度 | 0.995 |
| 独立对比两个冻结多边形的IoU | 约0.9915083973（不是上述置信度） |
| WGS84 bbox | `[116.317593455,40.001278869]` 至 `[116.317893863,40.001841842]` |
| bbox中心 | `[116.317743659,40.0015603555]`，非测绘中心 |
| OSM原标签 | `name=科学馆`、`name:en=Science Building`、`wikipedia=zh:清华大学科学馆` |

[清华官方介绍](https://www.tsinghua.edu.cn/info/1360/1394.htm)说明它由墨菲设计、1919年落成、位于大礼堂西南、总建筑面积3550平方米。[校友总会风物文章](https://www.tsinghua.org.cn/info/1954/13286.htm)进一步说明三层、中心草坪西侧、红砖灰坡顶、青瓦钢窗及黄铜门、门额文献拼写 `SCIENCE BVILDING`。3550平方米是历史报道的**总楼面面积**，不是冻结地图占地面积。

不是靠最近POI选中；不是生命科学馆、1999年新理学院楼或科学博物馆。函数核验完整冻结坐标环、名称、来源way、关联方式、置信度、底模高度、投影中心和根位置；有变化即报错而不是自动转用相邻对象。

## 实际取得的照片与使用边界

独立从[清华校园景观](https://www.tsinghua.edu.cn/zjqh/xyfg/xyjg.htm)中明确标注“科学馆”的图片元素取得原URL，2026-10-12下载并实际查看：

- 本地：`references/science-hall-official-east.png`
- [原图URL](https://www.tsinghua.edu.cn/__local/C/0B/77/28AE6C8C1B44A60206B4268D9C5_F6A46B23_A372E.png)
- 1920×900，669486字节
- SHA256：`abebdca24686de98f168ba47ebc258d97c271f0672ad8844e4c92100936f88db`
- `license: 'license-local-reference-only'`：未查得自由再发布授权，照片只作本地参考，不做模型纹理或在线/打包分发。
- 完整保留原始照片，无裁切/水印删除；页面未提供拍摄日期，不把它称为1919年历史原图或2026年新拍。
- 元数据：`data/science-hall-references.json` 是**单个SITE对象**，含既有站点字段，不是 `{sites:[...]}` 全局目录替代品。

只有**一张成功获取且建筑可验证的正面照片**。补充检索中的失效历史图链接、四大建筑手绘标题画、院所会议合照和无关横幅均未混入照片索引；不为凑照片数量误收素材。侧后照片仍待补充。

照片支持的特征：

1. 长三层红砖体量及浅色石基，正门朝东面向中心草坪。
2. 窗列不是均匀格子：左翼“三联—单—三联—单—三联”，上层正中两窗。右翼和底层有爬藤、树木遮挡，补全明确标成估算。
3. 中央窄凸出砖墙与**小三角山墙**，下部为跨两层高的**圆拱入口**、扇形钢格窗、横门额带、铜色双门与浅石台阶。没有编造四柱大门廊。
4. 大面积灰褐四坡顶，两条独立的长低屋顶采光窗；中央小山墙并非整栋高山墙屋顶。
5. 照片两端低建筑、远方天文台、树木、爬藤和施工围挡都不属于该冻结轮廓，本模块不建这些对象。

模型只用程序生成低对比砖/瓦 `DataTexture` 和程序英文点阵字形；贴图启用 mipmaps、`LinearMipmapLinearFilter`、`LinearFilter`、瓦面anisotropy 8／砖面4，避免远景屋面噪点。没有浏览器DOM、Canvas、网络或照片加载依赖。

## 已知限制

- 只重建照片可辨识东立面特色，西侧/南北端为全高安静外壳及石基，没有虚构逐窗后立面、服务入口或室内。
- 右翼用左翼节奏镜像补全；照片遮挡的底层窗位也不是测绘确认。
- 模型有整体四坡屋顶，但背坡、低采光窗进深、局部交接及约18.27米总高为估算；照片为高机位，有透视影响。
- 八级台阶、门扇钢格、灯具及山墙小浅色圆饰为近似。英文按文献古体拼写作程序字形示意，中文原手迹和不可读雕饰未摹造。
- `whole-footprint-estimate` 只承诺覆盖全轮廓的估算外壳，不声称surveyed、精确历史原貌或完整逐面复原。
