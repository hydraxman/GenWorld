# 校园建筑照片参考

可分发/本地边界：默认 `npm test` 核验来源元数据和模型，不读取任何校园或兄弟工程照片；本地图像字节检查有明确跳过原因，须显式 `npm run test:references` 才执行原哈希/尺寸断言，缺图即失败。默认 `npm run build` 的 `output\reference-photos.html` 仅含来源/许可与“未打包、未校验”提示；`npm run build:references` 才逐张验SHA256并复制本地照片。后者不授予再发布许可，不能随PR或模型分发。

2026-10-09 首批在本地保存6处地点、7张原图；第二批增加经管外观原图。2026-10-12 补充二校门现貌与历史照片，并扩展西体育馆、工字厅门房及水木清华临池后厦。当前地点／照片数量由 `reference-catalog.json` 和构建后的本地图库列出，接入三维模型的实际数量则由 `output\campus-coverage.json` 分开记录，**不把收集照片等同于完成重建**。原始旧素材下载日期未臆造；逐张尺寸、SHA256、发布页面和原图 URL 见索引，实际图片位于 `references\`。

主楼、大礼堂、学堂、紫荆照片的官方发布页为[清华校园景观](https://www.tsinghua.edu.cn/zjqh/xyfg/xyjg.htm)；老馆来源为[清华图书馆老馆页](https://lib.tsinghua.edu.cn/gk/gsfm/lg.htm)。主楼不是新清华学堂；紫荆公寓区不是紫荆园食堂室内。

舜德北门采用[官方导览原图](https://vr.tsinghua.edu.cn/u/cms/www/202410/23095758a7g3.jpg)，照片中可读“舜德楼”和工业工程系牌匾。内院照片来自[二次发布页面](https://www.sohu.com/a/462907673_641792)，并已用于本仓库舜德楼参考重建，不能把该图片标成官方域名原图，也不能将内院曲面当成外部北门。工业工程系地址另见[官方联系页](https://www.ie.tsinghua.edu.cn/lxwm.htm)。

建议重建顺序：先将既有舜德楼模型按坐标接回校园；新建模型从主楼正面体量开始，再做证据较清晰的大礼堂屋顶。照片不支持的背立面与尺寸仍需补图／测量，不将视觉推测包装成精确复原。

第二批按用户“经管优先”的要求，先接回已有经管红楼与灰色空中连廊，再重建大礼堂。经管照片来源为[清华教育基金会经管新楼项目](https://www.tuef.tsinghua.edu.cn/info/1072/2664.htm)，[官方报道](https://www.tsinghua.edu.cn/info/1181/37409.htm)用于核对组团位置与总高。照片中的灰框架空连接不证明其一定通向舜德，模型中通舜德的连廊按用户描述作示意。

这些图片仅用于本地观察，不进入模型材质；官方发布不意味着提供自由再发布许可。保留原有水印，在线展示、贴图或分发照片前另行核实授权。当前照片库只是首批，并非全校逐栋照片已经收集完成。

二校门现貌照片复用[校园景观页](https://www.tsinghua.edu.cn/zjqh/xyfg/xyjg.htm)中的原始图片；[清华风物之二校门](https://www.tsinghua.edu.cn/info/2116/81037.htm)配图为历史照片，仅补充全高比例观察。文章说明两翼短墙在1950年代后期拆去，主体在1966年被毁、1991年恢复重建，因此不把历史照片中的旧墙或全部细节无条件搬到现貌模型。

复核阶段的主要依据改用[校史馆《清华大学二校门的沧桑往事》](https://xsg.tsinghua.edu.cn/info/1003/3153.htm)明确标注“今景（贾珺摄）”的3264×2448正面照片，以及[官方《大美清华》](https://www.tsinghua.edu.cn/info/1183/94394.htm)的1500×1000现貌低机位斜视照片。两张都已实际查看、确认是北京二校门，不将同一组图里的清华学堂或文末新竹仿建校门误收为目标。

第五批复用本仓库已验证的官方西体育馆／工字厅／水木清华原图，实际复制进当前工程后再进入索引。工字厅图展示的是南门房，不是工字形主殿全景；水木清华图展示的是主殿后厦的临池立面，不能把两个视角误造为两栋独立主殿。

第六批科学馆原图从同一官方校园景观页中明确标注“科学馆”的条目提取，保存为 `references\science-hall-official-east.png`。该楼位于大礼堂西南、中心草坪西侧，冻结名称来源为 OSM way79701310；不把生命科学馆或邻楼收录为同一对象。另列完整采集与身份记录于 `data\science-hall-references.json`；单张照片支持正面，不代表侧后面已经核实。

同方部保存官方2018年西门近景与校史馆西山墙斜视两张原发布图片；两图都是同一入口，不虚报为两个方向。校档案说明匾额在朝草坪的西门，正门廊朝南；东部两层及南入口缺少完整照片。来源／哈希／许可和文字依据见 `data\tongfang-references.json`，工程将其列为局部重建。

老化学馆以化学系百年系庆页面和高分子所老馆故事配图互证身份，再使用 Wikimedia Commons 中葉又嘉（2019年）与 HoweyYuan（2024年）拍摄的南入口原图，均已记录 CC BY-SA 4.0 署名与链接。参考图库只计入四张原发布照片；转正／縮小的两张本地审阅图不冒称另外两个视角。完整记录见 `data\chemistry-hall-references.json`。新化学馆和何添楼仍保持原基模，未混用照片或替换相邻编号。
