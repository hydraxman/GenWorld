# 舜德楼庭院重建

根据地图轮廓与参考照片构建的三维建筑，包含北入口、开放庭院、圆体与玻璃厅。地图表示伟伦楼与舜德楼的组合轮廓；楼栋分界、隐藏立面、内部空间及部分尺寸仍为推定，不是测绘或施工模型。

## 运行

先在仓库根目录安装依赖，再进入本目录：

```sh
npm test
npm run build
npm run dev
```

通过终端显示的地址打开 `viewer.html`，可旋转、切换视角和导出 GLB。`index.html` 是影片入口。

```sh
npm run qa
npm run render
```

浏览器验收和视频制作还需要 Chromium、Python、Pillow 与 FFmpeg。用 `CHROME_PATH` 指定浏览器，`PYTHON` 指定解释器；输出目录和预览地址分别可用 `SHUNDE_OUTPUT`、`SHUNDE_URL` 覆盖。渲染输入校验还需通过 `SHUNDE_FONT_FILES` 指定实际字体文件。

## 模型与复用

来源、方位和推定范围见 [重建依据](docs/courtyard-reconstruction.md)。模型保持原凹形轮廓及庭院通道，不以完整盒体填补未证实空间。

校园和 [Logo 俯冲研究](../kaiwu-logo/studies/shunde-dive/README.md)复用此模型。立面细化需显式开启 `refinedFront`；周边建筑、硬地前场、树林与悬空连廊由独立模块装配，不改变原查看器的默认行为。连廊的位置及高度仍为示意。

`src/sem-building.js` 是西侧经管建华／李华组团与校园共用的照片参照模型：保留原ENU轮廓，北面通透门厅内有17m白拱，局部拱窗、陶板实墙、玻璃翼和圆柱依据清华校方及Gensler照片。来源与未知项见[校园照片索引](../tsinghua-campus/reference-catalog.json)；高低区分界、门厅宽厚、背面和通舜德连廊仍为推定。无参考照片纹理或外部字体请求。

用户提供的北向照片与校方原图哈希一致：红色楼体与东侧低层之间有真正向庭院贯通的北侧架空，上部玻璃连接体连续；低层玻璃后退，粗银色圆柱支撑金属底板。另一个较窄的通舜德玻璃桥下沿对齐主翼悬挑，不能与中间连接体混同。开口宽、净高、退距、柱径、连廊端点和标高均为照片比例推定。旧横向17m通道仍为未核实的平面估算，不再把北向照片作为该横向位置的证据；北门17m白拱另有官方文字依据。

下层前墙与侧墙按偏移边的交点统一收口，不在退让区留下独立窗片、栅栏状竖片或小白柱。通舜德桥从建华北部落点斜接舜德西侧的真实墙段，完整断面浅嵌入两端楼体；不得使用西墙延长线造成悬空，也不移动原楼体。路线和连接节点仍为估算，连廊内部未开放漫游。

舜德北门与建华北门的中央门扇向内打开，原玻璃／横档同步留出真实通道；`src/visitor-lobby.js` 共用有限门厅的地面、墙面、座椅及源坐标碰撞范围。校园工作台通过“进入建筑”或`?visit=shunde`／`?visit=jianhua`提供键盘、触屏漫游，独立查看器仍用原轨道控制。室内布置、边界和陈设明确标为示意，不是全楼室内、其他楼层或实际平面复原；室内告示也保留这一限制。

[Blender 工具](blender/README.md)保留的是独立历史模型，不应与当前庭院几何混同。GLB 保存几何与材质，不包含查看器的全部灯光及屏幕空间效果。
