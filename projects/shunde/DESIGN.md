# 舜德楼独立重建

采用真实 Three.js 构件建模，不贴照片平面。复用 shared PBR、天空/灯光、GTAO 与已改进枫叶，独立入口与模型，不改旧楼。

## 形体决策
- 正面识别优先：浅灰小尺度面砖、连续层带、规则统一玻璃、中央深色石材门框、两根贯通三排立面高度的圆柱、后退门厅与宽台阶。
- 估计米制范围沿用 spec 的宽62m、深30m、最高21.5m；不是测绘值或法定层数。以四排主要开窗+后退顶部窄窗复现照片。
- 中央高门厅不插入虚构中间楼板；分层仅移动两侧楼层、顶部与轻量推测隔墙。所有后/侧面、屋顶内部、室内均标推测。
- 庭院圆弧确有照片证据，但接合关系、方向、半径缺证。用独立可切换的“庭院圆弧体量假设”组呈现半圆而非武断闭合整圆；不得称精确复原。
- 连续地面与路面相接，无展示底座；树木集中边缘，前入口保持可见。树叶是共享CC0照片枫叶轮廓，不称真实树种。

## 46秒影像
0–8 正面三分之四全楼；8–16 主入口正面推进；16–24 右侧整体深度；24–31 门廊细节；31–36 全貌；36–46 分层打开、停留、原位闭合。无照片素材入成片。最终渲染交父代理。

## 验收
Node 几何契约先RED后GREEN；esbuild实编译；GPU浏览器检查正面/斜角/入口/展开末段；绝对时间重复seek；关闭状态导出GLB并GLTFLoader回读，验证网格、纹理、包围盒与法线方向；记录全部真实数据于qa/。
